# ProcessTrace

트렌치에 금속을 더 오래 증착하면 윗면과 측벽이 같은 만큼 두꺼워질까요? ProcessTrace에서는 공정 조건을 하나 바꾼 뒤, 전후 단면을 겹쳐 보며 이런 질문을 실험할 수 있습니다. 학부 반도체 공정 실습을 위한 웹 시뮬레이터로, 초급 구조부터 고급 소자까지 24개 예제를 제공합니다.

[실험실 열기](https://process-trace.vercel.app/) · [화면으로 따라 하는 튜토리얼](https://process-trace.vercel.app/tutorial)

## 첫 실습 · 트렌치에 금속 쌓기

1. **[Trench 예제](https://process-trace.vercel.app/#pvd)**를 열고 오른쪽 공정 목록에서 **09 PVD · 3/3**을 선택합니다. **기준으로 저장**을 눌러 원래 단면을 남겨 둡니다.
2. 같은 행의 **꺾쇠**를 눌러 조건을 펼칩니다. 증착 시간만 원래 값의 **1.2배**로 바꾸고 **공정 계산**을 누릅니다.
3. **기준 겹치기**를 켜고 트렌치 입구와 측벽을 비교합니다. 윗면과 측벽에서 각각 얼마나 자랐나요? 측벽 성장량을 윗면 성장량으로 나누면 측벽 피복률을 구할 수 있습니다.

2D에서는 X·Y·Z 축을 고르고 미니맵에서 절단 위치를 옮길 수 있습니다. 3D에서는 드래그로 회전하고 휠로 확대합니다. 게이트 안쪽이 궁금하면 해당 소자에서 **게이트 절개 보기**를 직접 켜세요.

## 공정 설계 점수 읽기

**공정 설계 평가**를 누르면 마지막으로 계산한 단계와 목표를 비교합니다. 중간 단계에서 누르면 화면에도 중간 평가로 표시됩니다. 점수는 시뮬레이션 코드가 계산하고, AI는 확인된 결과를 설명합니다.

| 과제 | 재료 형상 | 목표 치수 | 도핑 | 효율 |
| --- | ---: | ---: | ---: | ---: |
| 기본 과제 | 60 | 25 | — | 15 |
| 기본 과제 · 도핑 포함 | 40 | 20 | 25 | 15 |
| 목표 수정 | — | 85 | — | 15 |
| 목표 수정 · 도핑 포함 | — | 50 | 35 | 15 |

치수 허용오차는 기본 ±5%입니다. 효율은 목표를 충족한 뒤 기준 레시피 대비 **단계 수와 상대 비용**으로 평가합니다. 도핑 극성이나 필수 열처리 등 해당 과제의 필수 검사를 통과하지 못하면 총점은 최대 79점입니다. I–V 곡선은 구조 변화가 전류에 미치는 영향을 살펴보는 별도 실습입니다. [채점 코드](web/learning-score.js)

## AI는 어디에서 쓰나요?

- **화면 왼쪽 아래 챗봇**에서 ‘현재 공정 참고’를 켜면 선택한 단계와 계산 결과를 바탕으로 질문할 수 있습니다. 실습 튜터는 관측값, 원인 가설, 다음 실험을 나눠 제시합니다.
- **이미지로 목표 선택**은 첨부한 단면과 비슷한 예제를 추천합니다. 이미지는 Gemini API로 전송되며, 어떤 목표로 실습할지는 사용자가 고릅니다.
- **공정 지식 위키**는 GitHub에서 따로 읽는 자료입니다. 공정식, 적용 범위, 예제별 계산 사례를 담았으며 현재 챗봇에는 연결하지 않았습니다. [위키 색인](https://github.com/orange3636s/aie_makerthon2026/blob/docs/process-knowledge-wiki/docs/llm-wiki/wiki/index.md)

## 계산 결과 해석하기

단면은 공정 단계별 재료 경계와 도핑 분포를 보여줍니다. 3D는 계산한 단면을 바탕으로 만들며, 일부 소자의 게이트 절개에는 폭 방향의 교육용 가정이 들어갑니다. **Live**는 입자와 빛의 진행 방향을 설명하는 애니메이션입니다. 실제 장비의 처리 시간, 양산 수율이나 전기 특성을 검증하는 도구로 쓰기에는 한계가 있습니다. [공정 모델](docs/LOCAL_PROCESS_MODELS.md) · [모델 및 데이터 출처](MODEL-DATA-PROVENANCE.md)

<details>
<summary><strong>개발자용 · Windows에서 로컬 실행하기</strong></summary>

Windows x64에서 Python 3.12 x64와 Node.js 22 이상을 준비합니다. 저장소 루트에서 다음 명령을 실행하세요.

```powershell
.\setup.cmd
.\start.cmd
```

설치는 처음 한 번만 하면 됩니다. 서버가 시작되면 [로컬 실험실](http://127.0.0.1:3001)을 엽니다. AI 기능도 쓰려면 [.env.example](.env.example)을 참고해 서버 환경변수 `GEMINI_API_KEY`를 설정하세요.

기본 검사는 `npm test`, 전체 예제의 단면·메시 검사는 `npm run test:rendering`, 웹 빌드는 `npm run build`입니다. 기본 예제는 저장된 계산 결과를 재사용할 수 있고, 조건을 바꾼 레시피의 계산 시간은 공정 수와 서버 자원에 따라 달라집니다.

</details>
