# ALD 사이클과 성장 두께

반응물 펄스와 퍼지를 나눠 표면 반응을 반복한다. 반응이 포화된 구간에서는 사이클 수가 두께를 예측하는 간단한 변수가 된다.

## 계산과 가정

T ≈ N × GPC. N은 사이클 수, GPC는 nm/cycle, T는 nm이다. 초기 핵생성 지연이나 깊은 구조에서의 불충분한 노출·퍼지는 일정 GPC 가정을 깨뜨린다.

자체 실습의 예상 두께는 4 nm와 8 nm다. 동일한 초기 표면과 같은 포화 조건을 가정한 결과다.

## 직접 확인하기

GPC를 0.10 nm/cycle로 가정하고 40회와 80회의 두께를 예측한다. 이 수치만으로 바닥 피복률까지 알 수 있는지 토론한다.

**사이클을 두 배로 늘리는 것과 한 번의 펄스를 두 배로 늘리는 것은 같은가?** 포화된 표면에서 추가 펄스 시간이 같은 양의 성장을 보장하지 않는다. N과 펄스 시간을 별도 변수로 다룬다.
