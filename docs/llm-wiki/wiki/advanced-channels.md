# FinFET·GAA·MBCFET·CFET의 게이트 중앙 단면

| 예제 | 절개에서 볼 구조 | 확인할 위치 |
|---|---|---|
| FinFET | 돌출된 Si 핀의 윗면과 두 측면을 감싼 게이트 | 게이트 중앙 X 단면에서 핀과 기판의 연결 |
| GAAFET | 예제의 가는 와이어 채널 한 개 | 게이트가 채널 아래까지 이어지는지 |
| MBCFET | 예제의 넓은 나노시트 세 장 | 시트 사이에 게이트와 절연막이 들어가는지 |
| CFET | 예제의 하부 nFET과 상부 pFET | 두 층의 위치와 층간 절연 |

**관찰 순서** · 전체 공정 보기에서 금속 플러그를 확인한 뒤 게이트 절개를 직접 켠다. 게이트 길이 중앙을 가로지르는 단면과 S/D 쪽 단면이 다르게 보이는 것은 정상이다. 절개는 내부 구조를 보여주기 위한 교육용 재구성이며 폭 방향 형상에는 가정이 들어간다.

MBCFET도 GAA 계열이다. 표의 와이어·시트 수와 CFET 적층 순서는 이 저장소 예제에 해당한다. 실제 제품의 채널 수나 전류를 이 단면에서 추정하지 않는다.
