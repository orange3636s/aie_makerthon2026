# 이온 주입의 깊이와 농도

주입 에너지는 평균 침투 깊이에, 도즈는 단위 면적당 주입량에 관계한다. 주입된 총 농도와 전기적으로 활성화된 농도는 구분한다.

## 계산과 가정

이상화한 깊이 분포 C(z) = Q exp(−(z−Rp)²/(2σ²)) / (√(2π) σ). Q는 cm⁻², z·Rp·σ는 cm로 맞추면 C는 cm⁻³이다. 표면 경계, 결정 채널링과 산란 때문에 실제 분포는 비대칭일 수 있다. 마스크 아래의 주입량도 별도로 판단해야 한다.

P는 인 원소의 기호이며 Si에서 도너로 쓰인다. p형을 나타내는 소문자 p와 구분한다. 농도 그래프에서는 마스크가 열린 위치를 먼저 정하고 깊이 방향으로 비교한다.

## 직접 확인하기

MOSFET의 S/D 주입에서 에너지와 마스크를 고정하고 도즈만 바꾼다. 열린 영역의 최대 농도와 게이트 아래 분포를 비교한다.

**도즈를 두 배로 하면 최고점이 두 배 깊어지는가?** Rp와 σ가 고정된 가우시안에서는 최고 농도가 두 배가 된다. 최고점의 깊이는 같다.
