# MOSFET의 게이트와 S/D 도핑을 따로 읽기

기본 레시피에서 2단계는 산화막 ALD, 3단계는 Poly-Si LPCVD, 4~9단계는 게이트 패터닝과 노출막 제거다. 10단계에서 S/D에 인을 주입하고 11단계에서 활성화한다. 게이트의 증착 중 도핑과 열린 Si의 주입은 서로 다른 공정이다.

**같은 파란색이면 같은 주입인가?** 3단계에서 이미 게이트가 도핑 색을 가졌는지 확인한다. 10단계에서는 같은 단면 위치에 기준을 고정하고 마스크 아래와 양쪽 노출 Si를 비교한다. 재료 색과 도핑 농도 범례는 별개다.

**실험** · 게이트 도핑을 고정하고 S/D 도즈만 바꾼 두 레시피를 비교한다. 10단계에서는 총 농도, 열처리 뒤에는 활성 농도를 기록한다. 서로 다른 농도 필드를 같은 측정값처럼 비교하지 않는다.
