# 공정 변경에서 I–V 곡선까지

MOSFET 실습에서는 게이트 산화막과 활성 도핑이 다른 역할을 한다. 단순 평면 모델에서 단위 면적당 산화막 용량은 Cₒₓ = εₒₓ/tₒₓ이다. 산화막 두께를 바꾸면 게이트 결합이 달라지고, S/D 활성 농도를 바꾸면 접근 저항이 달라질 수 있다. 게이트 Poly-Si 도핑의 변화에는 일함수와 게이트 공핍 효과도 관여한다.

**비교 순서** · Vds와 전류 축 단위를 고정한다. 산화막 두께만 바꾼 두 곡선에서 같은 Vgs의 Id와 문턱 부근 변화를 읽는다. S/D 농도 실험은 원래 산화막 조건으로 돌아간 뒤 따로 수행한다.

**다른 소자** · PN 접합 예제는 순방향 전압에 대한 다이오드 전류를 계산한다. 게이트 전압에 대한 MOSFET 전달 곡선과 축 의미가 다르다. 현재 장채널 근사나 저준위 주입 근사를 실제 소자의 단채널 누설 또는 항복 예측으로 확대하지 않는다.
