# 목표 치수를 맞춰도 만점이 아닌 이유

**예시** · 기본 도핑 과제에서는 형상 40점, 치수 20점, 도핑 25점, 효율 15점으로 평가한다. 도핑 목표가 있는 사용자 수정 과제에서는 치수 50점, 도핑 35점, 효율 15점이다. 원래 형상과의 일치도는 후자의 목표를 대신하지 않는다.

**점검 순서** · 목표 허용오차와 필수 재료를 확인한다. 도핑종·기판 극성·열처리와 노광 해상도 등 적용되는 필수 검사 결과를 읽는다. 목표 충족 전에는 효율 점수가 보류된다. 계산 전 입력만 바꾼 학생에게는 마지막 계산 결과를 새 레시피의 관측값처럼 설명하지 않는다.

**질문** · 더 짧은 플로우면 무조건 더 높은가? 필요한 열처리를 생략해 검사가 실패하면 공정 수를 줄여도 효율 점수를 회복하지 못한다. 반대로 목표를 만족하는 대체 플로우는 기준 순서와 다르다는 이유만으로 실패로 단정하지 않는다.
