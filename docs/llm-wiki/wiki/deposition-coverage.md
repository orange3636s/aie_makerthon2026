# 트렌치의 단차 피복

윗면이 같은 두께로 성장해도 측벽과 바닥의 성장량은 달라질 수 있다. 입구가 먼저 닫히면 내부에 빈 공간이 남을 수 있다.

## 계산과 가정

측벽 피복률 = 측벽 두께 / 윗면 두께. 바닥 피복률도 바닥 두께로 별도 계산한다. 모두 같은 길이 단위를 사용한다. 피복률은 형상, 입사 방향, 표면 반응에 의존한다. 공정 이름만으로 일정한 값이나 보이드 발생을 단정할 수 없다.

윗면과 측벽의 두께는 각각 해당 면에 수직인 방향으로 읽는다. 서로 다른 단계의 누적 두께를 섞으면 한 단계의 피복률을 잘못 계산할 수 있다.

## 직접 확인하기

트렌치에 같은 윗면 두께를 목표로 증착하고 입구·측벽·바닥을 비교한다. 서로 다른 깊이에서 측정한 위치도 기록한다.

**윗면과 바닥만 보면 입구가 닫힌 시점을 알 수 있는가?** 중간 단계의 입구 폭도 비교한다. 마지막 단면 하나만으로 빈 공간이 형성된 시점을 확정할 수 없다.
