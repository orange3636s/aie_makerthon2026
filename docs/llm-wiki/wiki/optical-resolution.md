# 노광 해상도와 패턴 전사

같은 광학 조건에서 짧은 파장은 더 작은 패턴을 분리하는 데 유리하다. 실제 전사에는 마스크와 감광막, 노광량, 초점도 관여한다.

## 계산과 가정

교육용 해상도 척도 R = k₁λ/NA. λ를 nm로 입력하면 R도 nm이며 NA와 k₁은 무차원이다. R은 해상도 척도다. 완성된 선폭이나 소자의 기술 노드 명칭과 동일시하면 안 된다.

같은 k₁·NA라면 193 nm의 해상도 척도는 248 nm일 때의 약 78%다. 이는 두 광학계에 같은 가정을 넣은 연습값이다.

## 직접 확인하기

k₁과 NA를 고정해 248 nm와 193 nm 광원의 R을 비교한다. 그런 다음 초점 오차를 바꿔 단면에서 확인할 항목 하나를 정한다.

**더 짧은 파장을 골랐는데 설계 치수가 틀릴 수 있는가?** 가능하다. 마스크 폭, 초점, 현상과 후속 식각에 따른 치수 변화를 단계별로 분리해 본다.
