지식 페이지 14개에서 공정별 수식과 적용 범위, 소자 비교, 계산 사례를 찾아볼 수 있다. 아래 JSON은 기초 카드 요약이다.

ProcessTrace 실습용으로 새로 작성한 한국어 공정 카드 모음이다. [카드](cards.json)는 공정 이름이나 태그로 찾아보고, 각 카드의 `related` ID를 따라 다음 주제로 이동할 수 있다.

| 주제 | 살펴볼 질문 |
|---|---|
| 열산화 | Si 계면 이동량과 산화막 두께는 왜 다른가? |
| 이온 주입 · 열확산 | 도즈를 바꾸는 것과 열처리 시간을 바꾸는 것은 분포에 어떤 차이를 만드는가? |
| 광학 노광 · 식각 | 해상도와 마스크 선택비가 각각 제한하는 것은 무엇인가? |
| 증착 · ALD | 윗면 두께만으로 측벽과 바닥 상태까지 판단할 수 있는가? |
| CMP | 금속 채움 후 연마하면 어떤 전극이 분리되는가? |

## 카드 읽기

`model`은 교육용 근사식과 단위, `limit`은 적용 조건, `exercise`는 자체 실습이다. 모든 식이 현재 시뮬레이터의 내부 계산식과 일치하는 것은 아니다. 직접 만든 수치는 학습용 가정이며 실제 장비 측정값과 구분한다.

이 디렉터리는 정적 자료다. 서버 호출, 챗봇 검색, 모델 재학습 없이 GitHub에서 읽을 수 있다. 카드를 추가할 때는 고유 ID를 부여하고 관련 카드 링크를 확인한다.
