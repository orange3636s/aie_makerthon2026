# 본선 시연 전 시나리오 검증 — 2026-10-28

검증 대상: simulation 2.0, Windows CPU, Python 3.12, 형상 계산 4.6.2 / 주입·열처리 4.7.0. 실제 계산을 실행하여 결과를 검사했다. 실험 장비 데이터나 상용 TCAD에 대한 정확도 검증은 아니다. 사용자의 최종 요청에 따라 **외부 LLM API와 인식 정확도는 이번 최종 검증 범위에서 제외**했다.

## 자동 검증

| 범위 | 케이스 | 결과 |
|---|---:|---|
| 16개 기본 예제 + 공정 조합·오류 복구 | 35 | 모두 통과 |
| 각 관찰 파라미터를 독립적으로 최솟값·최댓값 적용 | 110 | 수정 후 모두 통과 |
| 16개 예제의 모든 파라미터를 동시에 최솟값·최댓값 적용 | 32 | 수정 후 모두 통과 |
| 반복 주입 누적, 에너지/깊이, B/P 보상, ALD 성장, CVD/PVD 피복 경향 | 5 | 모두 통과 |

위 182건의 개별 결과와 시간은 `qa-results.json`에 기록했다. 추가로 6개 목표를 새로 계산한 결과와 저장된 목표를 같은 ROI에서 비교해 모두 100점을 확인했다. 단, 이 점수는 **내부 재현성**이지 실제 제조 구조와의 정확도 100%가 아니다.

검사 조건은 계산 종료뿐 아니라 빈 결과 여부, 재료 경계 폐합, 좌표의 유한성, 단계 수, 실패 시 유효한 이전 단계 보존이다. 도핑 검사는 열처리 전후 농도 합의 상대 오차 0.5% 미만, 증착 후 기존 Si의 농도 보존, PR에 의한 주입 차폐를 포함한다. 피복 경향 검사는 측벽 두께를 측정할 수 있는 PVD 입사 방향성 지수 5와 CVD 기본 조건을 비교했다. 격자보다 얇아 측정되지 않는 막을 임의로 0%로 표시하지 않는다.

## 발견한 오류와 수정

| 문제 | 수정 및 확인 |
|---|---|
| 마지막 공정을 삭제해도 삭제 전 구조로 100점 채점 | 편집 시 유효한 결과 프레임까지만 보존. STI 마지막 질화막 제거를 삭제하면 56점, 잔류 질화막이 추가 재료로 반영됨 |
| MBCFET gap 80 nm 및 모든 최대 조건에서 적층 경계가 끊김 | 반사 경계에 걸린 hull의 누락된 cap만 연결. 내부의 끊어진 경계는 연결하지 않는 회귀 테스트 추가. 최대 조건 25프레임 완료 |
| 학습 영역을 벗어난 실패 단계를 완료 프레임에 포함 | 범위 검사 후에만 결과에 추가. 실패 전까지만 완료로 계산 |
| 앞 단계의 빈 값·범위 밖 값 때문에 다른 단계에서 원인을 찾기 어려움 | 전체 flow 검사 후 첫 오류 단계로 이동, 해당 입력에 초점. 빈 입력을 0으로 바꾸지 않음 |
| 손상되거나 예전 형식의 브라우저 저장 flow | 스키마 검사와 기본값 복원. 지원하지 않는 데이터는 안내 후 새 flow 시작 |
| 목표 로딩 중 정답 적용·계산 가능 | 목표 준비 전 종속 버튼 비활성화, 오래된 로딩 응답 무시 |
| 긴 flow를 선택할 때 가로 스크롤 위치가 초기화 | 가로 위치 보존, 선택 단계만 가로로 노출 |
| nm 예제를 본 뒤 역설계에서 nm 축이 남음 | 현재 선택한 구조의 단위를 사용 |
| tutorial 역설계 링크가 다른 hash로 덮임 | 직접 링크 위치 유지, 해당 가이드로 이동 |
| LOCOS 도핑이 부분 셀에만 표시, 산화 후 농도가 갱신되지 않음 | 현재 지원하지 않는 연계는 명시적 단계 오류로 중단. 정상 계산처럼 표시하지 않음 |
| PR이 남은 상태로 고온 열처리 허용 | PR 제거를 요구하는 공정 규칙 추가 |

좌측 메뉴와 tutorial 순서를 **Photo → Etch → C&C → 구조 → 소자**로 통일했다. 모든 사용자 공정 카드의 × 버튼과 우측 ‘공정 삭제’로 한 단계씩 삭제할 수 있다. Si substrate는 삭제하지 않는다.

## 직접 조작한 브라우저 시나리오

- STI 정답 적용 → 100점 → 마지막 단계 삭제 → 56점.
- 중간 단계 삭제, 앞뒤 순서 이동 → 이후 단계 미계산 처리, 이전 점수 제거.
- STEP 1 ALD 사이클을 비움 → STEP 9에서 계산 → STEP 1 오류로 이동 → 25로 수정 → 정상 재계산.
- C&C부터 시작 → ‘증착 후 추가’ 오류 → 해당 카드 삭제 → ALD 추가 → 정상 계산.
- 새로고침 후 저장한 flow 복원, 재계산 전 평가 비활성화.
- PVD/CVD/ALD 선택에 따른 조건 항목 전환, 계산 중 조건·삭제·이동 비활성화.
- MBCFET 20단계 선택 및 2D/2.5D 전환, 목표 비교와 재료별 점수.
- PNG 파일 다운로드 후 실제 PNG 형식과 크기 확인.

이미지 수동 선택은 외부 API 제외 요청 전에 확인했다. 이 사실을 AI 인식 성공으로 해석하면 안 된다.

## 재실행

Windows에서는 설치한 native Python을 사용한다. 4.7 transport가 별도 위치라면 `SIMULATION_NATIVE_ROOT`를 설정한다.

```powershell
npm test
.venv/Scripts/python tests/contours.py
.venv/Scripts/python tests/scenarios.py
.venv/Scripts/python tests/boundaries.py
.venv/Scripts/python tests/corners.py
.venv/Scripts/python tests/physics_trends.py
```

`tests/api.cjs`, `tests/classifier.cjs`는 이전 단계의 HTTP/모의 응답 계약 검사다. 실제 외부 LLM에 요청하지 않는다. 최종 비API 검증 집계에는 포함하지 않았다.

## 기획안과 발표에서 구분할 내용

| 기획안의 항목 | 실제 상태 |
|---|---|
| 학습자가 공정 순서를 구성하고 정방향 재현 | 구현: 최대 28단계, 5개 공정 그룹 |
| 단계별 2D·2.5D 비교, 순서가 달라도 구조로 평가 | 구현: 재료별 ROI IoU, 2.5D는 단면의 표시용 돌출 |
| 규칙 위반 피드백, 수정 후 재실험 | 구현 및 위 시나리오 검증 |
| 결과 기록 | 브라우저 flow 자동 저장, recipe/점수 JSON, PNG 저장 |
| 소형 CNN·합성 데이터 3,000건 학습 | 미구현. 현재 서비스의 기능으로 발표하지 않음 |
| 이미지 경계·치수 추출 및 직접 수정 | 미구현 |
| AI 공정 후보 최대 3개 생성·검증 | 미구현. 현재 정답 flow는 사람이 작성한 기준 예시이며 유일한 제조 정답이 아님 |
| 이미지 자동 선택 | 서버 키 연결이 필요한 선택적 구조 분류. 이번 요청의 검증 범위에서 제외 |

현재 계산은 10 nm 격자의 교육용 모델이다. 공정 전부가 동일한 물리 수준은 아니다. Photo는 PR 기하, C&C는 이상적 global planarization, 일부 관찰 예제는 기하/유효 속도 모델이다. 장비 보정, 결함/TED, 도핑과 산화의 재분배, I–V 특성은 검증하지 않는다. 내부 합성 결과만으로 실제 SEM 일반화 성능을 주장할 수 없다.

## 5분 발표에 맞춘 시연 동선

1. **0:00–0:40** 문제: 최종 단면에는 중간 마스크와 희생층이 남지 않아 공정 순서를 추론하기 어렵다.
2. **0:40–1:10** 두 구조 비교 화면과 사용자가 직접 구성하는 flow를 설명한다. AI 범위는 실제 구현 상태대로 한 문장으로 구분한다.
3. **1:10–2:40** STI 기준 flow를 열고 마지막 질화막 제거를 삭제한다. 남은 구조와 56점을 보여주고, 삭제된 공정의 역할을 설명한다. 다시 적용하거나 조건을 수정해 재계산한다.
4. **2:40–3:30** Photo/Etch 조건 하나를 바꿔 단면이 어떻게 달라지는지 보여준다. 여러 조건을 동시에 바꾸지 않는다.
5. **3:30–4:15** MBCFET 2.5D에서 SiGe 제거 전후의 nanosheet를 비교한다. 계산이 필요한 화면은 발표 시작 전에 한 번 실행한다.
6. **4:15–5:00** 실제 테스트 범위, 교육적 의미, AI 연결과 물리 보정의 남은 과제를 제시한다.

시연 전에는 로컬 서버와 공개 사이트를 각각 열어 두고, 실제 발표 PC에서 글자 크기·가로 flow 조작을 점검한다. 계산 지연에 대비해 검증된 결과를 준비하되 저장된 결과임을 숨기지 않는다. 위 동선은 권장 구성안이며 5분 실측 리허설은 아직 수행하지 않았다.

질의응답에서는 “왜 이 flow가 유일한 정답인가?”, “100점이 제조 가능성을 뜻하는가?”, “AI와 물리 엔진의 역할은 무엇인가?”, “실제 SEM에 검증했는가?”를 구분해 답한다. 현재 점수는 제조 이력·전기 성능·산업 공정 타당성을 확정하는 값이 아니다.
