# 전체 예제·공정·I–V 검증 (2026-11-01~02)

검증 대상은 기본 예제 24개, 초기 Wafer를 포함한 520개 화면(496개 공정), 대안 플로우 48개, I–V 지원 소자 11종입니다. 자동 검사와 개발자 사용 흐름 점검이며 실제 학생 대상 사용성 연구나 장비 실측 보정 검증은 아닙니다.

## 학술 검토의 기준과 한계

- MOSFET: 300 K 장채널 square-law, Cox와 문턱전압, 기판 극성, Poly-Si 일함수와 공핍, S/D 접근 저항을 검토했습니다. 실제 소자의 정량 I–V를 보장하는 TCAD 모델은 아닙니다. [Stanford EE116 MOS 강의](https://poplab.stanford.edu/files/ee116/L30to32_MOScapMOSFET.pdf)
- FinFET/GAA/MBCFET/CFET: 계산 단면에서 L/EOT를 추출하되 유효 채널 폭·이동도는 가정입니다. 실제 3D 전기장, 단채널 효과, 양자효과, BSIM-CMG를 계산하지 않습니다. CFET는 상·하부 독립 FET 곡선이며 인버터 전달 곡선이 아닙니다.
- Charge Trap: ONO 적층의 직렬 정전용량을 반영합니다. 전하 포획, program/erase, 메모리 보존시간은 지원하지 않습니다. 이번 수정은 저장층 측정 오류를 바로잡은 것이며 메모리 동작 모델을 추가한 것은 아닙니다.
- PN: 활성 농도 최고값을 균일 접합 농도로 대신 쓰는 Shockley 근사입니다. 면적·수명·이상계수는 가정이며 고준위 주입, 재결합, 항복은 제외합니다. 보호 산화막 변화가 MOS 게이트처럼 PN 곡선을 바꾸면 오류로 판정합니다.
- ALD: 약 0.1 nm/cycle는 대표적인 교육용 기준입니다. 모든 전구체·재료의 실제 GPC가 같다는 뜻이 아닙니다. native 형상 계산은 최대 10개 묶음 사이클로 가속하며 원자층 해상도를 주장하지 않습니다. [Beneq의 ALD 성장률 설명](https://beneq.com/insights/batch-ald-blog/)
- H₃PO₄: 165°C의 45 Å/min 사례를 속도 기준으로 사용하고, 활성화 에너지 약 53.1 kJ/mol을 0.55 eV로 근사했습니다. 서로 다른 문헌의 대표값을 조합한 교육용 응답이며 특정 막질·농도·수분 조건의 보정식이 아닙니다. [Micron의 질화막 식각 사례](https://patents.google.com/patent/US20060011586A1/en), [고온 인산 식각 연구](https://www.sciencedirect.com/science/article/pii/S0167931719303478)
- 두께·도핑을 바꾼 전체 공정에서는 후속 식각·마스크·S/D 접근 저항도 변할 수 있습니다. 따라서 산화막 증가가 모든 전체 레시피에서 전류를 단조 감소시켜야 한다고 판정하지 않습니다. 동일 구조의 전기 입력 검사와 실제 공정 재계산을 구분합니다.

## 실행 결과

- 최종 브라우저 검사: 24개 예제 / 520개 단계 / 2,080회 2D·3D 렌더 PASS. 별도 형상 회귀 검사: 3,990개 메쉬 / 4,680개 단면 PASS.
- 전체 `npm test`와 배포용 웹 빌드 PASS. 기본 예제 24개, 대안 48개를 native로 재계산하고 기본 24개·MOSFET 시연 6개 캐시를 현재 모델 버전으로 갱신했습니다.
- 24개 예제 / 520개 프레임: 독립 작업 폴더에서 native 재계산, 닫힌 경계·유한 좌표·유한 농도 확인.
- 496개 공정 / 3,024개 기본값·활성 숫자 경계값: 유한 응답 및 ALD GPC 단위 확인. 모든 극값 조합을 native로 계산했다는 뜻은 아닙니다.
- 역설계 UI: 24개 예제 / 520개 단계 / 2,031개 숫자 입력값 / 48개 Live 렌더 확인. 백그라운드 탭에서는 의도적으로 정지되는 rAF 대신 fixture가 시점별 redraw를 요청하여 두 프레임의 차이를 검사합니다.
- 반응형: 390, 768, 1,024, 1,366, 1,920 px에서 문서 가로 넘침 없음. 모바일·데스크톱 2D/3D와 튜토리얼 5단계를 직접 확인.
- HTTP: 입력·캐시·오류 복구 35건, 동기 서버·동시 요청·AI 키 미설정 24건. 튜터의 잘못된 질문·단계·대상 및 출처가 다른 요청 차단도 확인.
- 도핑 병렬성: 같은 작업 디렉터리에서 동시에 계산한 B/P 주입·열처리 농도장이 단독 실행과 일치하고 임시 폴더가 남지 않음.
- 단위 검증: 11종 I–V, Poly-Si/기판/S/D 농도·극성, 단위 변환, SONOS 내부 경계, 공정 응답의 브라우저/서버 일치 29건.
- 깊은 리세스(RCAT 등)의 채널 중심이 농도 격자 밖이면 기판 농도를 가정합니다. 해당 구간의 채널 극성을 검증했다고 표시하지 않고 I–V 모델 가정에 명시합니다.
- 성능: 로컬 실제 API의 5종 Poly-Si 소자 × 3개 도핑 설정은 저장된 형상을 재사용하여 약 1.5~2.8초였습니다. 새 형상 계산은 복잡한 예제에서 15초를 넘습니다. 모든 사용자 조합의 15초 이내 완료를 보장하지 않습니다.
- SONOS 산화막을 1.5배 증가시키면서 식각 시간을 유지하면 남은 blocking oxide 때문에 S/D 주입이 실패하는 것이 정상입니다. I–V 산화막 비교 실험에서는 blocking/tunnel oxide 개구 식각 시간도 1.5배 늘려 노출된 Si를 확보했습니다. 사용자 입력을 자동 보정한 것은 아닙니다.
