MOSFET

구조와 도핑 분포

이온 주입 이후 Si·SiGe에 계산 농도를 직접 표시합니다. n형은 파란색, p형은 분홍색이며 10¹⁴–10²⁰ cm⁻³의 로그 범위로 색 농도를 조절합니다. 활성화 전에는 총농도, 활성 농도가 계산된 이후에는 활성 농도를 표시합니다. 실제 SIMS 측정이나 전기 동작 검증이 아닙니다.

2D는 X/Y/Z 절단 위치를 바꿀 수 있습니다. 3D는 계산된 단면을 일정 깊이로 확장한 표시 모델이며 깊이 방향으로 균일하다고 가정합니다. 선택한 마스크는 회색으로, 개구부의 주입·노광 방향은 화살표로 표시합니다.

단계를 누르면 구조가 바뀌며 우측 꺾쇠를 눌러 조건을 펼치거나 접습니다. 레시피 변경은 공정 계산으로 반영합니다.

플로우 후보와 자가 진단

역설계에서 공정 설계 평가 문제를 풀면 기존 플로우와 대안 2개가 카드로 열립니다. 카드를 선택하면 편집 화면으로 돌아가 조건을 바꿀 수 있습니다. 이전 설계는 되돌리기로 복구할 수 있습니다. ‘목표 이탈 · 실험용’ 후보는 오답 원인을 탐구하기 위한 조건이며 정답 플로우가 아닙니다. 공정 계산 후 현재 결과를 다시 평가하세요.

표시된 시간은 입력값의 합계입니다. ALD에 퍼지 시간이 입력되어 있으면 대칭 A/퍼지/B/퍼지 주기로 합산합니다. 이송·준비·승온 시간은 제외합니다. 상대 비용은 기존 평가기의 교육용 가중치로 계산하며 실제 제조원가·성능·수율을 뜻하지 않습니다. High-k/Low-k 재료의 전기적 장점을 형상만으로 가산하지 않습니다.

평가에서는 관측 수치 → 오지선다 진단 → 근거 작성 → 해설 → 조건 수정·재계산 순으로 진행합니다. 형상·치수·농도·공정 효율은 코드가 계산합니다. AI는 기준 대비 공정 차이를 분석해 검토할 항목을 선택합니다. 문제의 정답은 해당 근거에 대응하는 확인 조치이며, 서술 이유 자체는 자동 채점하지 않습니다. 오답이면 재시도하고 AI 연결이 없으면 수치 기반 문제를 풉니다. 판단은 실제 제조 불량의 확정 진단이 아닙니다.

학습 기록은 이 브라우저에 최근 30회까지 저장합니다. 이전 제출과 현재 점수를 비교할 수 있습니다. 다른 PC로 동기화되지 않으며 브라우저 데이터를 지우면 사라집니다.

장비 조건 · 교육용 응답 모델

하나의 레시피에서 시간·온도·압력·파워를 조절합니다. 기존 예제의 기준 속도는 고급 모델 설정에 보존하며, 기준 조건에서의 속도에 응답 계수를 곱합니다. 장비 조건 계수는 실측 보정 전의 교육용 가정입니다. 범위 밖 장비·재료로 일반화하거나 실제 팹 레시피로 사용하지 않습니다.

PVD: R = R₀(Power/500) × 1.25/(1+압력/20) × 2F/(F+50). 압력 단위는 mTorr, F는 Ar sccm입니다. 입사 방향성 지수는 20(5/압력)^0.4를 2–40으로 제한합니다.

CVD: R = R₀ × Arrhenius(T; 400°C, 0.3 eV) × (F/100)^0.4 × 2p/(p+1) × 플라즈마 항. p는 Torr이며 PECVD의 플라즈마 항은 (Power/500)^0.3, Thermal CVD는 1입니다. 기존 장비 조건 레시피는 저장된 재료별 계수와 범위를 유지합니다.

위 식은 모델에서 정한 작동 범위 내의 경향 비교용입니다. PVD 압력 증가가 모든 장비에서 동일한 속도 변화를 만든다는 뜻이 아닙니다. 계산 전 예상 두께와 서버의 평면 기준 응답은 동일한 식을 사용하며, 실제 측벽·바닥 형상은 표면 수송 계산에 따라 달라집니다.

광원과 비용 평가

KrF 248 nm, ArF 193 nm, EUV 13.5 nm를 선택합니다. 해상도 검사에는 R = 0.6λ/NA를 사용하며, 노광 패턴 폭이 R보다 작으면 미충족으로 평가합니다. 공정 노드명은 실제 패턴 치수가 아니며 EUV도 sub-nm 선폭을 직접 보장하지 않습니다.

Exposure 단계의 교육용 비용 가중치는 KrF 2, ArF 3, EUV 6입니다. 실제 장비 가격이나 원가 배수가 아닙니다. 목표 형상·치수·필수 조건을 충족한 뒤 비용 효율을 비교하며, EUV 선택 자체에 가산점은 없습니다. 다중 패터닝의 최종 선폭을 단일 노광 폭과 혼동하지 않습니다.
