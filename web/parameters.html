공정 결과와 평가 점수는 그대로
Live 재생과 공정 계산은 무엇이 다른가요?

Live는 입자 이동 등 공정 원리를 보여주는 개념 애니메이션입니다. 조건을 바꾼 뒤에는 ‘공정 계산’을 눌러 새 결과를 확인하세요. 3D는 계산된 2D 단면을 일정 깊이로 돌출한 모델이며, 깊이 방향의 실제 공정 수송을 계산한 결과는 아닙니다.

04 / DESIGN & IMPROVE

관찰한 다음에는 직접 설계해 보세요.

실험실

한 조건이 만드는 차이

완성된 레시피에서 한 변수만 바꾸고, 이전 결과와 비교합니다.

역설계

목표까지 가는 공정 만들기

‘목표 수정’에서 치수·농도·허용오차를 정하세요. ＋로 공정을 추가하고 계산한 뒤 ‘공정설계 평가’를 누르세요.

불량분석

왜 잘못됐는지 찾아보기

제시된 문제와 레시피를 보고 원인을 추론합니다. 조건을 수정하고 개선 여부를 확인하세요.

점수에서 무엇을 확인하나요?

형상 · 치수
목표와 얼마나 겹치는지, 같은 위치의 치수가 얼마나 다른지
도핑 · 공정 이력
농도 조건과 필요한 주입·열처리가 충족됐는지
효율
목표를 만족하면서 불필요한 단계와 상대 비용을 줄였는지

수치 평가는 코드가 계산합니다. 수정한 과제는 지정 치수·농도와 필수 조건을 채점하며, 원본 형상은 참고용입니다. AI는 결과 해석과 다음 실험을 돕습니다.

막힐 때는 AI 튜터에게

좌측 아래 말풍선을 눌러 “현재 단계에서 시간을 늘리면 무엇이 달라져?”처럼 물어보세요.

후보 비교 · 저장 · 평가의 범위

‘후보 보기’에서 예제 flow를 불러오고 대안을 비교할 수 있습니다. 진단 문제가 제시되면 후보와 근거를 작성해 보세요. 공정 순서가 다르다는 이유만으로 오답이 되지는 않습니다.

비용은 교육용 상대 지수입니다. 형상·도핑 평가는 실제 전기 동작이나 제조 수율을 보장하지 않습니다. 학습 기록은 현재 브라우저에 저장되며 다른 PC와 자동 동기화되지 않습니다. 중요한 레시피는 ‘레시피 저장’으로 내려받으세요.
