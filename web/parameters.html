예제 파라미터역설계 계산식유사도 평가

MOSFET

단면과 그래프

실험실과 역설계의 Profile은 계산된 단면에서 추출합니다. 표면 높이는 각 x 위치의 최상단, 재료 두께는 같은 x 위치에서 해당 재료의 수직 구간을 합한 값입니다. 측벽 피복률과는 다릅니다.

농도·깊이는 측정선이 지나는 Si·SiGe 내부의 계산 농도를 로그 축으로 표시하며 SIMS 실측 데이터가 아닙니다. 깊이 0은 해당 위치의 가장 높은 반도체 표면입니다. 활성 농도가 계산되지 않았거나 측정 위치에 데이터가 없으면 값을 만들지 않습니다.

이전 단계 또는 고정한 계산 결과와 비교할 수 있습니다. RMSE는 두 곡선의 x 좌표가 일치하고 양쪽에 값이 있는 점에서만 계산합니다. 레시피 변경 후에는 공정 계산으로 결과를 갱신하세요. 미리보기는 저장된 조건의 계산 결과이며 채점에 반영되지 않습니다.

플로우 후보와 자가 진단

실험실 또는 역설계의 ‘플로우 후보’에서 기준 조건과 대안 2개를 비교합니다. 24개 예제 모두 실제 엔진으로 실행한 조건을 제공합니다. ‘목표 이탈 · 실험용’ 후보는 오답 원인을 탐구하기 위한 조건이며 정답 플로우가 아닙니다. 공정 계산 후 현재 결과를 다시 평가하세요.

표시된 시간은 입력값의 합계입니다. ALD 퍼지·이송 시간 등 미입력 시간은 제외합니다. 상대 비용은 기존 평가기의 교육용 가중치로 계산하며 실제 제조원가·성능·수율을 뜻하지 않습니다. High-k/Low-k 재료의 전기적 장점을 형상만으로 가산하지 않습니다.

평가에서는 관측 수치 → 오지선다 진단 → 근거 작성 → 해설 → 조건 수정·재계산 순으로 진행합니다. 형상·치수·농도·공정 효율은 코드가 계산합니다. 서술 이유는 자동 채점하지 않으며 AI 분석은 제출 후 기존 수치와 공정 차이를 설명합니다. 판단은 실제 제조 불량의 확정 진단이 아닙니다.

학습 기록은 이 브라우저에 최근 30회까지 저장합니다. 이전 제출과 현재 점수를 비교할 수 있습니다. 다른 PC로 동기화되지 않으며 브라우저 데이터를 지우면 사라집니다.
