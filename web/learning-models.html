조건을 바꾸고, 결과로 설명하기

학습 분석은 계산된 단면을 읽는 도구입니다. 공정 모델의 오차를 없애거나 실제 장비 측정을 대신하지 않습니다.

실험 순서

  1. 공정 단계를 선택하고 한 변수의 변화 방향을 예상합니다.
  2. 조건을 바꾸고 공정 계산을 실행합니다.
  3. 학습 분석에서 농도·막 두께·치수를 비교합니다.
  4. 역설계의 최종 목표 조건을 확인하고 관측 근거를 기록합니다.

웨이퍼 도핑과 색상

Wafer에서 p형(B), n형(P), 진성과 농도를 선택합니다. NMOS는 p형 기판, PMOS는 n형 몸체를 사용하며, 소스·드레인은 반대 극성의 고농도 영역입니다. 기본 기판은 10¹⁶ cm⁻³, CFET의 저농도 몸체는 5×10¹⁴ cm⁻³입니다. CFET 하부는 p형, 상부는 n형입니다.

교육용 모델은 균일하고 완전히 활성화된 배경 농도를 Si 영역에 더합니다. 준비된 Si 채널도 같은 몸체 농도를 사용하고, CFET 상부는 n형으로 설정합니다. 순농도 Nnet = ND − NA이며, p형은 붉게, n형은 푸르게 표시합니다. 10¹⁴–10²⁰ cm⁻³의 고정 로그 색상척도를 2D/3D에 공통 적용합니다. 배경 도핑의 열처리 재분포·편석은 생략하고 기존 주입·확산 분포와 선형 중첩합니다. 기판 도핑은 S/D 주입·활성화 공정을 대신하지 않습니다.

구조 원리: MIT OCW · MOS 구조

Poly-Si 게이트

Poly-Si 게이트는 증착 중 도핑된 전도성 박막으로 모델링합니다. NMOS는 n+, PMOS는 p+, 기본 농도는 10²⁰ cm⁻³입니다. Poly-Si 증착 단계에서 p/n 종류와 10¹⁷–10²⁰ cm⁻³ 농도를 바꿀 수 있으며, 같은 소자의 Poly-Si 게이트 막에 공통 적용합니다. 게이트가 쌓이는 단계부터 식각 후 남은 영역까지 같은 도핑을 유지하며, SADP의 임시 Poly-Si 맨드릴은 제외합니다. 게이트 농도는 Si 내부 S/D 주입·확산 격자와 별도로 저장합니다. 300 K 일함수 Φg = 4.61 ∓ min(0.56, kT/q ln(Ng/10¹⁰)) eV, 기본 10²⁰ 게이트 대비 일함수 차이를 Vfb에 더합니다. 같은 극성 게이트의 문턱점 공핍 폭 Wg = Qdep/(qNg), 전압강하 Qdep·Wg/(2εSi), 직렬용량 1/Ceff = 1/Cox + Wg/εSi를 적용합니다. 반대 극성은 축적 근사로 Wg=0입니다. 전기 모델은 바이어스별 공핍 변화·고농도 축퇴·입계 트랩·게이트 확산을 해석하지 않습니다. 완전 공핍 조건에서는 곡선 대신 안내를 표시합니다.

근거: IBM Research · n+/p+ Poly-Si CMOS 게이트

모델 원리: TU Wien · Poly-Si 일함수와 게이트 공핍. 수식은 이 플랫폼의 교육용 근사입니다.

S/D 도핑 입력

주입 카드에서 n+ 인(P), p+ 붕소(B)를 선택하고 주입 피크 농도 또는 도즈를 조절합니다. 피크 입력은 Cpeak = Q / (√(2π)σ)로 환산하며 σ는 선택한 종·에너지의 공개 표에 있는 headSigma입니다. 환산 농도는 무한 매질 가우시안 근사입니다. 실제 주입은 기존 dual-Pearson IV 모델로 계산하고, 마스크·후속 확산·활성화에 따라 최종 농도가 달라집니다. I–V는 이 최종 활성 농도를 사용합니다.

p형 기판은 NMOS, n형 기판은 PMOS로 해석합니다. 기판 극성을 바꾸면 게이트 권장 극성이 바뀌며 게이트 농도는 유지됩니다. 이후 게이트를 독립적으로 변경할 수 있습니다. S/D 종류는 각 주입 카드에서 별도로 선택해야 합니다. 서로 맞지 않는 극성이나 게이트 옆 미도핑 간격은 안내를 표시합니다. PMOS는 전압·전류 부호를 반전하고 정공 이동도를 전자 이동도의 0.4배로 근사합니다. CFET는 하부 p형·상부 n형 몸체를 유지합니다.

프로파일

도펀트 그래프는 native 계산 결과의 농도 격자를 깊이 방향으로 샘플링합니다. 실제 SIMS 측정 데이터가 아닙니다. 총 농도와 활성 농도는 다른 양이며, 도즈(cm⁻²)는 깊이 적분된 주입량, 농도(cm⁻³)는 체적당 원자 수입니다.

가우시안 주입 근사: C(z) = Q / (√(2π)σ) · exp[−(z−Rp)²/(2σ²)]. 단위 변환 후 적분량을 확인해야 하며, 유한한 영역과 마스크에 의해 분포가 잘릴 수 있습니다. 일정 확산 계수의 무한 매질 근사에서는 σ²(t) = σ₀² + 2Dt, D = D₀ exp(−Ea/kBT)입니다. T는 K입니다. 활성화는 확산과 별개이며 실제 고농도 군집화·결함·채널링은 이 식만으로 설명되지 않습니다.

막 두께 그래프는 각 x에서 선택 재료의 수직 교차 구간을 합산합니다. 재료 경계 우선순위를 적용하고 없는 재료는 0으로 표시합니다. 단일 중앙 트렌치 증착에서만 별도로 측벽/상부 증가 두께 비율을 추출합니다. 측벽은 트렌치 중간 높이의 양쪽 평균입니다. 복잡한 형상·닫힌 트렌치는 자동 피복률을 표시하지 않습니다.

소자 I–V · 교육용 개형

PN Junction과 10종 FET 예제에서 곡선을 비교합니다. 계산된 현재 단면과 목표 단면에 같은 전기 모델 입력을 적용합니다. 전기장·전류 수송 TCAD가 아니며 전기 동작 합격 판정에 사용하지 않습니다.

FET 계산

EOT = Σ(tᵢ × 3.9 / κᵢ), Cox = 3.9ε₀ / EOT
φF = (kT/q) ln(NA/ni)
Wd = √(4εSiφF / qNA)
Vth = Vfb + 2φF + qNAWd / Cox

SOI에서는 Wd를 min(Wd, Si 몸체 두께)로 대체합니다. FD/PD라는 예제 이름만으로 공핍 상태를 고정하지 않습니다. 중앙 Si/절연막/게이트의 연속된 수직 구간에서 EOT를 구하며 게이트 중간 높이의 폭을 L로 사용합니다. 리세스 소자는 양쪽 Si 표면과 중앙 Si 표면의 높이 차로 채널 길이를 보정합니다.

Vgs ≤ Vth: Id = 0
0 < Vds < Vgs−Vth: Id = μ Cox (W_eff/L) [(Vgs−Vth)Vds − Vds²/2]
Vds ≥ Vgs−Vth: Id = ½ μ Cox (W_eff/L)(Vgs−Vth)²

공정 조건 → I–V 변화

산화막·게이트 절연막 두께는 계산 단면의 EOT와 Cox에 반영합니다. 주입량·에너지·열처리를 바꾸면 계산된 순 활성 농도로 S/D 접근 저항을 다시 계산합니다.

Nsheet = ∫ max(0, 극성 × Nactive(z)) dz
Rsh = 1 / (q μ Nsheet)
Rs,d = Rsh × Laccess / W_eff
Vgs,int = Vgs − Id Rs
Vds,int = Vds − Id (Rs + Rd)

게이트 양옆 각각 100 nm의 Si 농도 열을 깊이 적분하고 평균합니다. Laccess = 100 nm, 접근 영역 이동도는 입력 이동도와 같다고 가정합니다. cm⁻³ 농도와 cm 깊이를 사용하며, 내부 전압과 전류가 일치할 때까지 이분법으로 계산합니다. CFET은 상부 pFET와 하부 nFET를 분리합니다. S/D 농도를 채널 배경 농도로 바꾸지 않습니다.

이것은 활성 도핑과 접근 저항의 관계를 관찰하는 교육용 근사입니다. 실제 접촉 면적·전류 경로·농도 의존 이동도는 추출하지 않습니다. 단순 확산으로 총 활성 면밀도가 보존된다면 곡선 변화가 작을 수도 있습니다. PN 소자의 보호 산화막은 게이트가 아니므로 두께만 바꾸어 전류를 강제로 변경하지 않습니다.

근거: NIST · 면밀도·이동도·면저항, ngspice · MOS 소스/드레인 직렬 저항.

고정 조건은 300 K, ni = 10¹⁰ cm⁻³, VSB = 0입니다. 대표 상대 유전율은 Si 11.7, SiO₂ 3.9, Si₃N₄ 7.5, HfO₂ 20, Al₂O₃ 9, HZO 25로 가정합니다. 박막 조성·온도별 측정값은 아닙니다. 이동도·배경 농도·Vfb·유효 폭은 단면에서 추정하지 않고 명시적 입력 가정으로 둡니다.

FINFET/GAA/MBCFET은 전체 게이트 둘레, 시트 수, 양자 구속을 이 단면에서 복원하지 않습니다. W_eff에 전체 유효 폭을 입력한 등가 장채널 곡선이며 BSIM-CMG가 아닙니다. CFET pFET는 nFET Vfb의 반대 부호와 전자 이동도의 0.4배를 가정하고, Vgs·Id를 음수로 표시합니다. 인버터 전달 곡선은 아닙니다.

Charge Trap은 현재 형상에 존재하는 절연막만 용량에 반영합니다. Si₃N₄가 없으면 화면에 알립니다. 트랩 전하, program/erase, 보존시간은 계산하지 않습니다. 모든 FET에서 누설·DIBL·접촉저항·속도 포화·양자효과는 제외되므로 미세 소자의 실제 성능을 예측하지 못합니다.

PN Junction 계산

I = Is [exp(V / nVT) − 1]
Is = q A ni² [Dn/(Ln NA) + Dp/(Lp ND)]
Dn,p = μn,p VT, Ln,p = √(Dn,p τ)
Vbi = VT ln(NA ND / ni²)

계산 Si 영역의 순 활성 농도 최고값을 균일한 NA·ND의 대용값으로 사용합니다. 접합 면적 A, 소수 캐리어 수명 τ, 이상계수 n은 입력 가정이며 μn=1350, μp=480 cm²/V·s입니다. 비균일 접합 수송, 직렬저항, 항복은 계산하지 않습니다. 전압 범위는 −0.3~0.6 V이며 큰 순방향 전압에서의 저준위 주입 가정도 실제 소자와 다를 수 있습니다.

근거: JKU · MOSFET 모델, UC Berkeley · EE105. 정밀한 다중 게이트 모델과의 구분: UC Berkeley · BSIM-CMG.

식각·증착을 해석할 때

ARDE는 깊이와 종횡비에 따른 식각률 변화, micro-loading은 국부 패턴 밀도와 크기에 따른 변화입니다. 같은 개념이 아닙니다. PVD/CVD/ALD를 선택했다고 항상 특정 피복률이나 불량이 결정되지는 않습니다. 실제 형상은 입사 분포·표면 반응·수송·조건에 의존합니다. 공정 입력의 온도·압력·파워 응답은 기준 조건에 대한 교육용 경험 모델이며 장비별 보정값이 아닙니다.

근거: EPFL CMi · Etch definitions. 보잉·마이크로트렌칭을 실제로 계산하지 않은 단계에서 발생 사실처럼 판정하지 않습니다.

목표 미션·AI 튜터·학습 기록

목표 치수는 예시 계산 단면에서 추출합니다. 공정 순서의 완전 일치가 아닌 형상 90% 이상, 각 목표 치수 ±5%, 해당 소자의 도핑·열처리 검사 통과로 목표 충족을 판정합니다. 점수는 기존 결정적 채점 코드가 계산합니다. AI는 점수를 생성하거나 수정하지 않습니다.

AI에는 서버에 일치하는 계산 결과가 있을 때만 검증된 수치 근거를 전달합니다. 캐시 만료·계산 결과 불일치 시 레시피 기반 설명으로 제한합니다. 관측, 원인 가설, 확인 질문, 다음 실험을 구분하지만 LLM 오류 가능성을 없앤 것은 아닙니다.
